# Aktuelle Fragenredaktion

Führend sind die drei aktuellen Fachbestände unter `content/`: Filmfragen, Schauspielerfragen und Preisfragen. Quellen, Attribute und stabile Fragen-/Wissensziel-IDs stehen direkt in den Frageobjekten. Frühere Lieferkopien, Gesamt-CSV, Bearbeitungsarchive und Lesestände werden nicht zusätzlich aufbewahrt; frühere Fassungen sind über Git nachvollziehbar.

Neue oder überarbeitete Fragen nach dem [Redaktionsvertrag](../Fragenredaktion.md) prüfen und unmittelbar im aktuellen Bereich pflegen. CSV dient als vorübergehendes Eingabeformat für den echten Importer. Fachliche Auswahlgruppen und technische Releasepakete bei Bedarf aus aktuellen Attributen und IDs erzeugen.

- [Aktueller Katalogaufbau und Übernahme](../Fragedaten-Organisation.md)
- [CSV-Format](../Importformat.md#aktueller-fragenbestand--07112026)
- [Preisfragen](../Preistraeger.md)
- [Prüfnachweise](../Pruefbericht.md)

Datierte ältere Beschreibungen in der Projektdokumentation sind historische Entscheidungen, keine zusätzlichen führenden Fragenbestände.
